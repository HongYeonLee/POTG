## 📝 소개
2024-2학기 이화여자대학교 컴퓨터공학과 오픈SW플랫폼 수업을 수강하며 작업한 공동구매 웹사이트 프로젝트 POTG입니다.

- POTG는 상품 등록 및 구입 시스템을 이용하여 학교 내 공동구매를 활성화하기 위해 제작된 프로젝트입니다.
- 마켓컬리를 레퍼런스로하여 제작하였으며, 수업이 요구하는 기능외에 공동구매, 마이페이지 기능을 구현하였습니다.
- Project Of The Genius의 준말로, 게임에서 최고의 플레이를 뜻하는 Play Of The Game에서 유래했습니다.
